# ValutaTrade Hub

Консольное приложение для учебной торговли валютами и просмотра портфеля.

## Запуск

Нужны Python 3.12 или новее и `uv`. В папке проекта выполните:

```bash
uv sync
uv run python main.py
```

Файлы пользователей и портфелей создаются при первой регистрации. Они остаются на компьютере пользователя и не добавляются в Git.

## Команды

- `register --username ИМЯ --password ПАРОЛЬ` — регистрация
- `login --username ИМЯ --password ПАРОЛЬ` — вход
- `show-portfolio [--base ВАЛЮТА]` — просмотр портфеля
- `buy --currency ВАЛЮТА --amount КОЛИЧЕСТВО` — покупка
- `sell --currency ВАЛЮТА --amount КОЛИЧЕСТВО` — продажа
- `get-rate --from ВАЛЮТА --to ВАЛЮТА` — просмотр курса
- `exit` — выход

Покупка и продажа изменяют баланс только кошелька выбранной валюты. Сумма в USD показывается для оценки; кошелёк USD при этих операциях не списывается и не пополняется.

## Курсы и настройки

Пока локальный файл `data/rates.json` отсутствует, приложение использует фиксированные учебные курсы. Если файл кэша есть, курсы читаются из него. Срок актуальности курса задаётся параметром `rates_ttl_seconds` в разделе `[tool.valutatrade]` файла `pyproject.toml`; сейчас он равен одному часу. Устаревший курс не используется.

Подключение внешних источников и команда обновления курсов относятся к следующему этапу проекта. Параметры путей к JSON-файлам и журналу также находятся в `[tool.valutatrade]`.

## Журнал операций

Покупки, продажи и ошибки этих операций записываются в `logs/actions.log`. Журнал создаётся автоматически, хранится только локально и не добавляется в Git.
